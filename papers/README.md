# Papers

这里把“别人已经发表的研究”和“我们自己的可公开技术写作”明确分开。

```text
references/  论文索引、引用信息、阅读笔记与复现关联
our-work/    尚在写作或准备公开的技术报告 / paper 草稿
```

## 使用原则

- 不直接提交受版权保护的论文 PDF，除非确认拥有再分发权；保存 DOI、arXiv 链接和阅读笔记即可。
- 每篇参考论文在 `references/reading-log.md` 留下“它解决了什么、核心机制、与本实验的关系”。
- `our-work/` 只放可公开的草稿与图表；不得放入内部资料、私有数据、账号信息或未经授权的结果。
- 当一个结论来自本仓库实验时，在正文中链接到对应 `reports/` 和 commit，以便复现。
